Compute Engine Basics

Lab Overview
• Cloud: GCP
• Duration: 90 minutes
• Exercises: 2 (Create the Linux Compute Engine VM, Connect with gcloud SSH and create the completion file)
• Validations: 3
• Deployed services: Compute Engine virtual machine (Windows labvm), VPC network, VPC subnet, VPC firewall rule, Deployment Manager deployment
• Scenario: Learners use the Google Cloud console to create a running Linux Compute Engine VM named `ubuntu-vm` in zone `us-central1-a`, using an `e2-micro`, the latest available Ubuntu LTS image, the pre-provisioned deployment-specific VPC, and the `10.10.0.0/24` subnet. From the Windows `labvm`, they use PowerShell and `gcloud compute ssh` over the ephemeral external IPv4 address and TCP/22 access to create `scenario2.txt` in the default GCP user’s home directory containing exactly `scenario 2 is completed`.
